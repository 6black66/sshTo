# sshTo

面向 Linux 的 SSH 桌面客户端。支持设备配置、独立终端标签页、可调整大小的左右/上下分屏、多级跳板，以及双栏 SFTP 文件传输。

## 开发与运行

需要 Node.js 22.12+、npm，以及 Linux 图形桌面环境。

```bash
npm ci
npm run dev
```

运行生产构建：

```bash
npm run build
npm start
```

打包 Ubuntu / Debian 安装包和 AppImage：

```bash
npm run pack
```

产物在 `release/`。`.deb` 使用 `sudo apt install ./release/sshto_1.0.0_amd64.deb` 安装；AppImage 添加执行权限后运行。AppImage 需要系统支持 FUSE，也可使用其 `--appimage-extract-and-run` 选项运行。

如果下载 Electron 时需要使用已有 HTTP 代理，可以在安装前设置 `ELECTRON_GET_USE_PROXY=true`，并配置 `HTTPS_PROXY`。无需在应用中配置外部服务。

## 使用

1. 点击“添加设备”，填写设备名称、主机、SSH 端口、用户名。支持密码或本地私钥文件；加密私钥可以填写口令。
2. 点击左侧设备即可连接。同一设备可以打开多个独立会话。首次连接需要在系统对话框确认主机指纹，指纹变化需核实后明确确认更新。
3. 使用右上角左右/上下分屏按钮同时显示终端，拖动终端间分隔条调整大小；点击终端选择活动设备。
4. 为目标设备添加有序跳板列表，例如 A、B。应用按“本机 → A → B → 目标”连接，每一级独立认证。跳板机必须允许 TCP 转发。列表中的跳板配置只使用其主机和认证信息，不递归展开它自己的跳板列表。
5. 文件面板左侧是本机，右侧始终对应活动终端的最终目标设备。双击文件夹进入，路径输入框按 Enter 跳转。Ctrl + 点击多选，拖到另一侧或点击上传/下载按钮开始传输。
6. 在传输队列查看进度、速度、取消和重试。传输绑定创建时的会话和路径，切换标签不会改变传输目标。完成后返回文件列表即可查看结果。

文件列表显示名称、大小和修改时间，时间按本机时区显示。文件管理默认占工作区的一半，可上下拖动终端和文件面板之间的横条调整高度，双击横条恢复默认比例。

手动在终端输入嵌套 `ssh` 不会更新连接路径或 SFTP 目标。需要准确显示设备路径时，请使用应用配置的跳板连接。

## 文件只读预览

双击文件或选中文件后按 Enter，可在应用内查看本地或当前设备的 UTF-8 文本，包括 XML、JSON、日志、脚本及源代码。目录仍通过双击进入，文件软链接读取其目标。

预览窗口显示来源设备、完整路径及文本内容，可滚动、选择文字和复制全部，按 Esc 或关闭按钮退出。 XML、JSON、Shell、Python、C/C++ 等代码和配置文件按类型进行语法配色，日志中的错误、警告和信息级别也使用不同颜色。普通文本不强制配色；超过 200 KiB 或高亮处理不可用时使用纯文本显示，预览上限仍为 1 MiB。预览不编辑、不保存、不执行文件内容，也不会自动刷新日志。打开后固定读取原设备及路径。

每次最多显示文件开头 1 MiB，超过会提示截断，复制仅包含已显示内容。空文件有单独提示；二进制、非 UTF-8 文件暂不支持。远程读取依赖 SFTP，超时、无权限及连接断开会显示错误，关闭窗口会取消未完成读取，不生成临时副本。

## 凭据与配置

配置存放在 Electron 的应用用户目录，Linux 默认 `~/.config/sshto/config.json`（可受 XDG 配置影响），带格式版本，采用临时文件加原子重命名写入，权限为 `0600`。

- 密码和私钥口令可选择加密保存，依赖 GNOME Keyring / libsecret 或 KWallet。系统凭据库不可用时，保存选项禁用，密码只保留在应用进程内存，重启后需重新填写。
- 不复制私钥，仅保存本地文件路径；私钥需要一直存在于该路径。
- 编辑设备时密码留空保留已有凭据；更换认证方式或私钥路径时会清除旧凭据。取消保存密码会删除持久凭据，本次运行仍可使用已输入的密码。
- 主机指纹按主机名与端口保存。应用不读取或修改系统 `known_hosts`。
- 配置文件包含主机、用户名等连接信息，不应作为公共文件分享；密文依赖当前系统凭据库，不能作为跨机器密码导出格式。

## 文件传输约定

浏览文件时会识别软链接的目标类型，目录软链接可双击或按 Enter 进入；目标不存在或无法访问时给出提示。文件和文件夹递归传输时仍跳过符号链接，并报告跳过数量。同名文件逐项询问覆盖或跳过。文件先写入目标目录中的临时文件，成功后重命名；取消或失败会尝试清理临时文件。上传覆盖要求服务器支持 OpenSSH 原子重命名扩展，否则报错并保留原文件。强制终止进程或网络完全中断可能留下 `.sshto-*.part` 临时文件。

无 SFTP 子系统的设备仍可使用 SSH 终端。第一版不包含远程设备间互传、拖出到系统文件管理器、断点续传、群发命令、SSH agent、云同步或自动重连。

## 验证

```bash
npm test                 # 配置、跳板路径、凭据存储与并发写入
npm run test:integration # 本地真实 SSH 协议服务：两级跳板、私钥、SFTP、断线等
npm run test:ui          # Electron 界面、四会话、分屏、拖拽和重启持久化
```

集成测试使用回环地址和临时目录，不访问外部设备，也不更改系统 SSH 配置。需要 `ssh-keygen`；界面测试另需 `Xvfb` / `xvfb-run`。界面测试使用隔离配置和关闭沙箱的测试进程，正常应用启动保留沙箱。

技术栈：Electron、React、TypeScript、xterm.js、ssh2。SSH、文件系统和凭据仅在主进程访问；界面通过隔离的 preload IPC 接口调用，不开放 Node.js。
