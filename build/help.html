sshTo · 使用说明

Linux SSH 桌面客户端，支持多会话终端、跳板连接和文件传输。

  1. 在左侧添加设备，填写主机、端口、用户名和密码，或选择私钥。
  2. 点击设备连接，核实并确认首次连接的 SSH 主机指纹。
  3. 使用右上角按钮切换左右或上下分屏，拖动分隔条调整大小。
  4. 在设备配置中依次添加跳板，连接路径显示在终端顶部。跳板必须允许 TCP 转发。
  5. 在文件面板左右两侧拖拽文件和文件夹，完成上传或下载。右侧对应当前活动终端的最终目标。
  6. 传输队列提供进度、速度、取消和重试。切换终端不会改变正在运行的任务目标。

双击文件或按 Enter 可只读预览 UTF-8 文本，包括配置、日志和脚本。XML、JSON、脚本和源代码支持语法配色。窗口支持复制及 Esc 关闭，每次最多显示文件开头 1 MiB；图片和其他二进制文件暂不支持。

终端及输入框支持右键复制粘贴和 Ctrl+Shift+C / Ctrl+Shift+V。终端 Ctrl+C 保留中断命令的用途；只读预览仅允许复制。传输同名文件时可勾选将覆盖或跳过应用到本次任务的所有冲突文件，同名目录自动合并。

密码加密保存依赖 GNOME Keyring 或 KWallet；不可用时仅在当前运行期间记住密码。私钥只保存文件路径。

终端内手动执行的嵌套 ssh 不会改变界面的连接路径或 SFTP 目标。符号链接在递归传输中跳过。不支持断点续传或设备间互传。
